# 태블릿 펜 입력 오타 교정 확인 절차

철자 쓰기 칸에 펜으로 쓴 글자가 **쓴 그대로** 들어오는지 실제 태블릿에서 확인하는 절차입니다. 펜 필기를 글자로 바꾸는 시스템 기능이 틀린 철자를 맞는 철자로 고치면, 틀린 답이 정답으로 채점됩니다. 이 결과로 펜 입력 방식을 정합니다.

## 왜 확인하나요

- 앱의 철자 칸(Flutter `TextField`)은 별도 코드 없이 iPad의 Apple Pencil 손글씨 입력(Scribble, iPadOS 14+)과 Android 14(API 34)+ 스타일러스 필기를 받습니다. Flutter 3.41의 `stylusHandwritingEnabled` 기본값이 켜져 있습니다.
- 철자 칸은 `autocorrect: false`, `enableSuggestions: false`로 키보드 자동 수정과 추천을 껐습니다. 이 설정이 펜 필기 인식에도 적용되는지는 문서로 확인되지 않았습니다.
- 사용자 보고에 따르면 iPad Scribble은 시스템 설정에서 자동 수정을 끌 수 없고, 고친 단어에 파란 밑줄을 표시합니다. 갤럭시 탭은 S펜 손글씨 입력, 삼성 키보드 필기, Gboard의 "텍스트 입력란에 쓰기"처럼 입력 경로가 여러 개라 경로마다 결과가 다를 수 있습니다.

## 판단 기준

| 결과 | 결정 |
| --- | --- |
| 철자 칸에서 오타 14개가 모두 쓴 그대로 들어옴 | 시스템 필기를 그대로 사용. 펜이 닿으면 "펜으로 써도 돼요" 안내만 추가 |
| 기본 칸에서는 고쳐지지만 철자 칸에서는 그대로 들어옴 | 위와 같음. 앱의 자동 수정 끄기 설정이 효과가 있다는 뜻 |
| 철자 칸에서 오타가 **하나라도** 맞는 철자로 바뀜 | 그 기기·경로에서는 시스템 필기로 채점하지 않음. 철자 칸의 펜 필기를 끄고 앱 자체 필기 칸을 제공(쓰고 나서 정답과 비교해 자기 채점) |
| 대문자나 띄어쓰기만 바뀜 | 문제없음. 채점은 대소문자와 연속 공백을 무시함 |

여러 기기 중 한 기기만 실패해도 그 기기·경로는 실패로 봅니다.

## 준비

### 기기와 설정 기록

기기마다 아래 내용을 먼저 적습니다.

- 기기 모델, OS 버전(Android는 설정 › 휴대전화 정보 › 소프트웨어 정보에서 Android 14 이상인지 확인)
- 펜 종류(Apple Pencil 세대, S펜)
- 키보드 앱과 버전(삼성 키보드, Gboard 등)
- 키보드 자동 수정 설정(iPad: 설정 › 일반 › 키보드 › 자동 수정, 갤럭시: 삼성 키보드 설정 › 입력 지원 › 맞춤법 자동 수정·예측 텍스트)

학생이 쓰는 상태 그대로 확인하려고 **자동 수정은 기본값(켬)으로 1회** 시험합니다. 시간이 되면 끈 상태로 한 번 더 합니다.

### 입력 경로별 켜기

| 기기 | 경로 | 켜는 곳 |
| --- | --- | --- |
| iPad | Apple Pencil 손글씨 입력(Scribble) | 설정 › Apple Pencil › 손글씨 입력. 언어에 English 포함 |
| 갤럭시 탭 | S펜 손글씨 입력(입력란에 바로 쓰기) | 설정 › 유용한 기능 › S펜 › S펜으로 텍스트 입력 |
| 갤럭시 탭 | 삼성 키보드 필기 모드 | 입력란을 누른 뒤 키보드의 필기 아이콘 |
| 안드로이드 태블릿 | Gboard 텍스트 입력란에 쓰기 | Gboard 설정 › 스타일러스 › 텍스트 입력란에 쓰기 |

메뉴 이름은 OS와 키보드 버전에 따라 다를 수 있습니다. 실제 이름을 기록표에 적어 둡니다.

### 앱 설치

- iPad: Mac에 연결하고 `flutter devices`로 기기 ID를 확인한 뒤 실행합니다. 서명 팀은 iPhone에 설치할 때와 같습니다.

  ```bash
  flutter run -d <ipad-device-id>
  ```

- Android 태블릿: 개발용 APK를 만들어 설치합니다. 결과물은 `build/app/outputs/flutter-apk/app-debug.apk`입니다.

  ```bash
  flutter build apk --debug
  ```

  ```bash
  adb install -r build/app/outputs/flutter-apk/app-debug.apk
  ```

## 시험할 칸

1. **시험 칸: 단어 찾기 입력창.** 앱 위쪽 돋보기를 누르면 열립니다. 철자 칸과 같은 입력 설정(자동 수정·추천 끔, 대문자 자동 변환 끔)입니다. 학습 단계를 거치지 않고 여러 단어를 빠르게 시험할 수 있습니다.
2. **비교 칸: 단어장 안의 "영단어 또는 뜻 검색" 입력창.** 단어장 탭 › 아무 단어장을 엽니다. 시스템 기본 설정(자동 수정 켬)인 칸입니다.
3. **확인 칸: 실제 철자 쓰기 화면.** 오늘 탭에서 학습을 시작해 철자 쓰기 단계까지 갑니다. 5문제 중 3문제를 일부러 틀리게 씁니다. "정답 확인"을 누르면 입력한 글자가 칸에 남으니, 그 글자와 채점 결과("잘 떠올렸어요." 또는 "한 번 더 보면 돼요.")를 함께 기록합니다.

각 단어는 펜으로 한 번에 쓰고, 칸에 들어온 글자를 고치지 않은 상태로 기록합니다. 파란 밑줄이나 추천 표시가 나타나면 그것도 적습니다. 다음 단어 전에 칸을 지웁니다.

## 기록표

기기·입력 경로·칸 조합마다 한 장씩 씁니다.

| 번호 | 쓴 글자 | 칸에 들어온 글자 | 바뀜(예/아니오) | 밑줄·추천 표시 | 메모 |
| --- | --- | --- | --- | --- | --- |
| 1 | recieve | | | | |
| … | | | | | |

머리말에 기기, OS, 펜, 키보드 앱·버전, 자동 수정 설정, 입력 경로, 칸(시험/비교/확인)을 적습니다.

## 결과 정리

- 조합마다 "오타 14개 중 바뀐 개수"를 셉니다.
- 시험 칸과 확인 칸의 결과가 다르면 확인 칸 결과를 따릅니다.
- 판단 기준표로 기기·경로별 결정을 적고, 이 문서 끝에 결과 표를 추가합니다.

기기 한 대와 입력 경로 하나에 30분 정도 걸립니다. 최소 범위는 iPad + Apple Pencil 1대, 갤럭시 탭 + S펜 1대(S펜 손글씨 입력, 삼성 키보드 필기 두 경로)입니다.
