# 제공 PDF 어휘 데이터와 Day·Part 활용 기록

기준일: 2026-10-16. 사용자 요청에 따라 **단어 데이터를 먼저 확보하고, 학년·난이도는 전수검사하면서 별도 정리**한다. 이번 결과는 두 PDF 전체에서 추출한 원천 데이터다. 학습 의미 분리, 편집 전수검사, 출시 승인이 완료된 앱 콘텐츠와는 단계가 다르다.

## 확보 범위

| 자료 | 첨부 파일의 실제 범위 | 본문 항목 | 예문·번역 쌍 | 원본 구성 |
| --- | --- | ---: | ---: | --- |
| 사랑 영단어 수능 2000 | 628쪽, 0001–2000 | 2,000 | 3,342 | Day 1–50, 각 40개, FIRST/SECOND HALF 각 20개 |
| EBS MY WORD COACH 중학 영단어 | 69쪽, 0001–0300 | 300 | 300 | Part 1의 Day 1–15, 각 20개 |
| 합계 | 원본 697쪽 보존 | **2,300** | **3,642** | 20개 단위 원본 묶음 115개 |

중학교 표지에는 1,200개·60일로 안내하지만, 첨부된 파일에는 300개·15일만 있다. Day 16–60의 나머지 900개를 확보했다고 집계하지 않는다. 서로 같은 철자의 60개 그룹은 출처별 항목을 유지했다. 대소문자를 정규화한 고유 표제어·구는 **2,240개**다. 동일 철자가 동일 의미라는 판단은 아직 하지 않았다.

본문에서 발음 표기 2,133건, 표현·연어와 번역 300쌍, 관련어 153건, 보충 메모 114건을 별도 필드로 보존했다. 어원 탐구 2쪽의 `auto`, `bio` 묶음은 보조 카드 6개와 예문·번역 6쌍으로 추가 구조화했다. 이 중 본문에 없는 표제어는 `automatic`, `autograph`, `autobiography`, `biography` 4개다. 보조 카드 수를 본문 2,300개에 섞지 않으며, 어원 설명은 교재에 인쇄된 주장으로 기록하고 정확성 검토를 남겼다.

교육과정 대표 목록과는 본문 항목 기준 정확한 철자 일치 1,166건, 변형·관련 형태 일치 131건, 대표 목록 밖 1,003건이다. 이는 자동 조회 결과이며 의미 동등성·학년·교육과정 적합성 검증이 아니다. 구와 파생어도 포함되어 있어 3,000개 목록에 없는 항목을 삭제하지 않는다.

| 유의어·반의어·파생/관련어 | 원문 기호와 색상에 따라 관계 보존 | 상세의 관련어, 혼동 비교, 객관식 오답 후보 제외 검토 |

| Double Puzzle·복습 정답 | 2쪽, 페이지 단위 | 철자 배열·완료 후 추가 연습 |

| 고교 색인 | 24쪽 원문, 본문 연결 2,000건 | 검색 결과의 원문 위치, 추출 누락 대조 |
| 표지·목차·이용 안내 | 5쪽, 페이지 단위 | 출처 안내와 자료 범위 확인 |
| 그림·인쇄 배치 | 원본 PDF와 페이지별 이미지 위치·크기 | 전수검사 원문 확인. 앱용 이미지 파일로 별도 반출하지 않음 |
| 외부 링크·음성 안내 | `externalReferences` | EBS `mid.ebs.co.kr` 안내 보존. MP3를 확보한 상태는 아님 |

문제 페이지의 지시문·선택지·대화·영영 정의·정답은 모두 페이지 원문에 남겼다. 개별 문항과 정답의 연결은 아직 검수 전이므로 채점 가능한 문제 수로 집계하지 않는다. 예문에 등장하는 `FactCheck.org`도 텍스트상의 외부 참조이며 데이터 수집 출처로 사용하지 않았다. 고교 예문의 `06모고`, `01수능` 등은 원문 표기를 보존했으며 시험 연도·문항 출처를 추가 검증했다고 표시하지 않는다.

## Day·Part를 앱에 활용하는 방법

**원본 구성은 자료를 찾아가는 기준으로 유지하고, 하루 학습량은 앱에서 조절한다.** Day 번호는 실제 달력의 날짜나 학생의 성취 수준을 뜻하지 않는다.

| 원본 구분 | 기록한 활용안 | 앱에서 필요한 처리 |
| --- | --- | --- |
| 교재 → Part → Day | 교재 순서대로 공부하는 코스·목차 | EBS에는 확인된 Part 1만 표시. 고교의 Half를 Part로 바꾸지 않음 |
| 고교 Day 40개 | 전반/후반 20개씩 또는 하루 목표 5·10·20·40개 | 현재 5개 라운드를 전·후반 각각 4회로 연결 가능 |
| 중학교 Day 20개 | 현재 5개 라운드 4회로 학습 | Part 1 → Day 1 → 1/4회차 식으로 이어하기 |
| 원본의 항목 순서 | 책과 앱을 함께 사용하는 학습·시험 범위 지정 | 원본 순서 보존, Day 범위 선택 후 시험 범위에 담기 |
| Day 완료 | 첫 학습 진도와 재학습 범위 | ‘한 번 학습함’과 뜻·철자 숙달을 분리해 표시 |
| Half/Day 테스트 | 해당 묶음 학습 후 선택적 점검 | 전반 시험은 전반 항목에만 연결. 정답 대조 후 출제 |
| Weekly Review 1·2 | Day 1–5, 6–10 누적 확인 | 5일마다 달력 알림을 강제하기보다 코스 진도에 맞춰 제안 |
| Part 완료 | 코스 진행률·종합 복습 | 중학 첨부본의 범위가 Part 전체와 같은지 확인 전 ‘Part 완전 수록’ 표시 금지 |

원천 묶음 ID는 `bookId + day + half`로 식별하고 `part`를 별도 필드에 보존했다. 예: `sarang-csat-2000:day:01:FIRST HALF`, `ebs-middle-excerpt:day:01:whole`. 서로 다른 책의 Day 1을 같은 단원으로 합치지 않는다. 다른 판본이나 번호가 다시 시작되는 Part를 추가할 때는 별도 판본 ID와 Part를 포함한 식별 규칙으로 확장한다. 현재 추출기는 등록된 두 파일의 SHA-256만 허용한다.

실제 앱 연동에서는 `sourceEntryId → senseId` 연결을 전수검사 결과로 만들고, 학습 진도는 기존 의미 ID에 유지한다. 같은 의미가 다른 교재나 Day에 다시 나와도 숙달 기록을 중복 생성하지 않는다. 원본 Day·Part는 여러 단어장에 포함되는 관계로 관리한다. 학년·레벨은 이 단원 번호와 독립적으로 판정하며, 학년 분류를 고쳐도 Day 구성·의미 ID·기존 진도를 바꾸지 않는다.

위 항목은 **활용 설계 기록**이다. 이번에 구현한 범위는 원천 단원 115개와 본문·자료 연결까지이며, 코스 선택·Day 진도 화면은 후속 앱 작업이다.

## 파일과 재추출

원본과 육안 전사 보정은 [원천 폴더](../content/sources/user-provided/)에, 파생 결과는 [가져오기 폴더](../content/imports/pdf-books-v1/)에 있다.

- `entries.jsonl`: 본문 2,300개. 원본 번호·쪽수·영역, Day·Part·Half, 모든 뜻·예문·표현·관련어·원문 블록·해시.
- `pages.jsonl`: 697쪽 전체 텍스트와 자료 종류·이미지 메타데이터·단원 연결.
- `units.json`: 115개 묶음, 항목 순서와 관련 문제·요약 자료. 권장 앱 라운드 크기 5개.
- `source-index.json`: 고교 색인 2,000건과 본문 항목 연결.
- `study-supplements.jsonl`: 출처를 연결한 어원 보조 카드 6개.
- `overlap.json`: 중복 철자와 교육과정 원천 대조 결과. 자동 병합하지 않음.
- `review-queue.jsonl`: 자동 플래그가 있는 265개 항목과 현재 내용 해시. **전수검사는 본문 2,300개 모두 대상**이며, 이 파일은 우선 확인 목록이다.
- `library.sqlite`: 위 데이터를 조회하는 원천 라이브러리. 앱의 `assets/content/content.sqlite`와 스키마·용도가 다름.
- `manifest.json`: 원본·도구·보정·산출물 SHA-256, 수량, 확인 상태.

```sh
.venv-content/bin/python -m tool.content.pdf_books \
  --high content/sources/user-provided/sarang-csat-2000.pdf \
  --middle content/sources/user-provided/ebs-middle-excerpt.pdf \
  --output content/imports/pdf-books-v1 \
  --cache content/imports/.layout-cache

.venv-content/bin/python -m unittest discover -s tool/content/tests -v
```

API 키 없이 로컬에서 재현한다. 재추출 명령은 해당 출력 폴더의 파생 파일을 다시 만든다. 사람의 편집 원고·검수 결정은 별도 파일에 저장하고 `entryId`와 `contentHash`로 연결해야 한다. 원천 전사 보정은 `extraction-corrections.json`, 어원 페이지 전사는 `study-supplements.json`에 근거와 함께 남긴다. 원본 PDF를 직접 수정하지 않는다.

## 확인 결과와 다음 전수검사

기계 검증 기록은 [검증 JSON](../analysis/pdf-content-import-verification.json)에 남겼다. Python 전체 51개 테스트(이 추출기의 회귀 테스트 12개 포함)를 통과했고, 별도 폴더에 재추출한 JSON·SQLite와 manifest가 모두 바이트 단위로 일치했다. SQLite 무결성·외래 키와 항목별 내용 해시도 확인했다.

본문 번호는 고교 1–2000, 중학교 1–300이 각각 누락·중복 없이 이어진다. 고교는 뒤쪽 색인의 **단어·쪽수 2,000건 전부**가 본문과 일대일로 일치한다. 예문·번역 및 표현·번역의 빈 값, 해결하지 못한 빈칸은 자동 검사에서 0건이다. 이는 문법·번역·의미 일치에 대한 전수 편집 승인과 다르다.

발음 문자 매핑이 깨진 `housework`, `various`, `fireball` 3건은 400 dpi 원문 이미지와 대조해 전사했으며 원래 깨진 값도 보존했다. 고교 물리적 411·423·435쪽의 하단 Day 표기가 단원 순서와 충돌하여 해당 15개 항목에 표시했다. 411쪽은 옆 표기 `DAY 34-02`와 하단 `DAY 01-02`가 실제로 다르다. 묶음은 항목 번호와 단원 표지를 기준으로 연결하며 원문 표기를 덮어쓰지 않는다.

품사·뜻이 여러 개인 200건, 세미콜론으로 뜻을 나눈 58건, Day 충돌 15건, 발음 전사 3건을 표시했다. 플래그는 중복될 수 있다. 쉼표로 나열한 뜻처럼 자동 규칙으로 잡지 못한 다의어도 전수검사에서 확인한다. 원문 오탈자·불완전한 문장을 자동으로 정상 문장으로 가장하지 않는다.

다음 작업은 출처 항목별로 뜻·품사·예문·표현·관련어를 대조하고 학습할 의미를 나누는 것이다. 이 과정에서 학년·난이도를 별도 편성 원장에 기록하고, 근거가 없는 배정은 미분류로 남긴다. 기존 100개 파일럿과의 의미 중복을 판정한 뒤 앱 의미 ID 연결·다의어 패키징·Day 코스 기능을 진행한다.

## 출처와 이용 상태

이번 원천은 사용자가 제공하고 활용을 요청한 PDF 두 개다. 원문에 있는 문제 지시문은 학습 자료로 보존하며 작업 지시로 실행하지 않는다. 각 PDF는 원본 바이트를 복사해 SHA-256으로 식별했다. 파일명 `22`를 2022 개정 교육과정 인증이나 중학교 특정 학년 배정으로 해석하지 않는다.

EBS PDF에는 무단 복제·2차적 저작물 작성 등에 관한 제한 문구가 인쇄되어 있어 manifest에 그대로 기록했다. 두 자료의 앱 배포 이용 권한은 확인 전 상태(`not_verified_for_distribution`)다. 로컬 데이터 정리 결과를 출시 허가 또는 사람의 검수 승인으로 바꾸지 않는다. 현재 앱에 설치된 콘텐츠는 기존 개발 파일럿 100개 표제어·154개 의미이며, 이번 2,300개 원천은 아직 출시 패키지에 설치하지 않았다.
