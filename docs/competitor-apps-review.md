# 영단어 앱 5종 기능·리뷰 비교와 리보카 보강 방향

조사일: 2026-10-19. 대상은 워드마스터 학습앱, 해커스 중고등 보카, 나는 영단어, 영단어 마스터, 저절로암기 영단어입니다. 스토어 설명과 공개 리뷰만 참고했고, 앱을 설치해 쓰지는 않았습니다.

## 앱별 요약

### 워드마스터 학습앱
- **기능:** 교재 연계(인앱 4,900–9,900원 또는 교재 구매 혜택), 단어카드(I Know / I Don't Know, 영어만·뜻만 보기, 랜덤), 테스트 5종(뜻 고르기, 영단어 고르기, 한글 뜻 입력, 영단어 입력, 문장 빈칸), 레벨테스트, 오디오 모드(반복 횟수, 수면 모드, 백그라운드 재생), 계정 기반 기록 동기화, 광고 없음.
- **칭찬:** 책 없이 자투리 시간 학습, 학원 단어시험 대비, 테스트 유형이 다양함, 예문과 유의어·반의어 수록, 광고 없음, 깔끔한 디자인.
- **불만(1★ 대부분):** 리뉴얼 뒤 로그인·계정 찾기 실패로 산 단어장과 기록을 잃음, 폰과 태블릿을 동시에 못 씀, 신버전은 오프라인 사용 제약, 맥에서 실행 안 됨.
- **반복 요청:**
  - 틀린 단어만 모아 다시 시험 보기(가장 많음, 구버전에 있던 기능이 빠져 혹평)
  - 다음 단어로 넘어갈 때 발음 자동 재생
  - 정답일 때는 바로 넘기고 오답일 때만 멈추기
  - 유의어·반의어 테스트, 품사 표시, 하루 목표량, 테스트 기록 추이
  - 영어만·뜻만 보기를 화면에서 바로 전환
  - 오디오를 영-한-영-한 순서로 듣기, 원하는 단어만 무한 반복
- **채점 문제:** 한글 뜻 입력에서 뜻 순서가 다르거나 일부만 쓰면 오답 처리됨. 괄호·가운뎃점 입력이 어려움. 입력 도중 키보드가 영어로 바뀜. 영단어 입력 때 키보드 추천에 정답이 뜸.

### 해커스 중고등 보카
- **기능:** 도서 연계, Day별 단어 보기와 가리기, 학습카드 자동재생(표제어·발음·뜻·예문·파생어, 백그라운드 재생), 재생 간격·배속·반복 설정, 복습게임 4종(보카버블, 짝맞추기, 예문복습, 음성복습), 나만의 단어장(밑줄, 셀로판지 가리기), 기간제 이용권.
- **리뷰:** 결제 후 실행 안 됨, 앱이 튕김, 화면이 저절로 새로고침됨, 어휘 유형 전체선택 요청, 품사 표시 요청, 고등편·숙어·수능완성 단어장 요청. 칭찬은 1건뿐("공부하기 좋아요").

### 나는 영단어 (직접 경쟁 위치)
- 우리 앱과 방향이 가장 비슷합니다: 오프라인, 회원가입 없음, 기록은 기기에만, 빈도순 코스, 한 번에 10단어(아는 단어는 넘기기 → 카드 → 확인 문제 10개, 모두 맞혀야 다음 세트).
- **콘텐츠:** 표제어 8,704개, 품사별 뜻 갈래, 💡팁(혼동어·연어·반대말·어원), 예문·해석, 발음기호·한글 발음, 비슷한 말, 품사별 발음 차이.
- **복습:** 게임 5종(60초 스피드런, 문장 빈칸 추리, 단어 던전, 듣고 잡기, 카드 뒤집기), 오늘 복습, 취약 단어, 즐겨찾기, 코스 랜덤 복습, 나의단어장(그룹, 직접 만든 단어).
- **습관:** 연속 학습일, 리마인더, 통계, **백업 파일 내보내기·가져오기와 되돌리기**, 다크 모드.
- **약점:** 배너·전면 광고, 신규 앱이라 검증 전.

### 영단어 마스터 (엘란)
- 영어 4,500개(중등 기초–TOEFL)와 일본어·중국어 단어장.
- **퀴즈 4종:** 단어→뜻, 뜻→단어, 듣고 고르기, 철자 입력.
- **복습:** 간격 반복(최대 120일, 끝까지 맞히면 '마스터'로 졸업), 밀린 복습은 한 번에 30단어씩.
- **습관:** 오답노트, 즐겨찾기, 검색, 하루 목표, 연속 학습일, 학습 시간·XP, 알림(복습 수 표시, 누르면 바로 복습), **홈 화면 위젯**(연속일·오늘 복습 수), 백업·복원.
- 광고·결제·가입 없음.
- 업데이트 기록에서 배울 점: 밀린 복습이 끝나지 않던 문제, 앱을 내려둔 시간까지 학습 시간에 쌓이던 문제, TTS 음성이 없는 기기에서 아무 반응이 없던 문제를 고쳤습니다.

### 저절로암기 영단어
- **기능:** 잠금화면 반복 노출(다른 앱 위에 표시 권한 필수), 사진 속 영단어 인식으로 단어장 만들기(OCR), 단어별 이미지 여러 장, 숏폼 복습, 목표 개수 퀴즈, 기초–공무원·TOEFL 단어장, 즐겨찾기, 발음 속도 조절. 광고와 유료 구독(월 약 3만 원이라는 리뷰 있음).
- **칭찬:** 폰을 켤 때마다 단어를 보게 됨, 이미지와 소리를 함께 보는 학습, 자투리 시간 활용.
- **불만:**
  - 잠금화면을 끌 수 없음(여러 건), 배터리 소모, 주머니 속에서 눌려 영상이 재생됨, 다른 앱보다 먼저 뜸
  - 잠금해제 버튼 근처 광고가 움직여 잘못 눌림(여러 건), 광고를 안 눌러도 쇼핑앱이 열림
  - 뜻·발음 오류, 단어와 맞지 않는 이미지, 다의어의 한 뜻만 보여 줌
  - **품사 없음**(여러 건), 예문이 없는 단어장, 구독 해지 방법을 찾기 어려움, 환불 요청
- **요청:** 하루 몇 개만 반복하는 소분류·일일 목표, 잠금화면에서 범위 안 랜덤 출제, 발음 반복 횟수 선택, 예문 해석만 따로 숨기기, 손글씨 연습 때 답이 보이지 않게 하기, 타자로 확인하기.

## 리뷰에서 읽히는 학생의 핵심 요구

1. **기록과 산 콘텐츠를 잃지 않는 것.** 워드마스터 1★ 리뷰 대부분이 로그인·계정 문제로 기록을 잃은 이야기입니다. 오프라인 사용과 폰·태블릿 병행도 같은 맥락입니다.
2. **틀린 단어만 다시.** 모아 보기보다 **모아서 다시 시험**을 원합니다.
3. **빠른 테스트 흐름.** 정답은 바로 넘기고, 오답은 멈춰서 확인하고, 발음은 자동으로 나오기를 원합니다.
4. **시험 대비 정보.** 품사, 유의어·반의어, 문장 속 쓰임(빈칸), 파생어처럼 학원·내신 시험에 나오는 정보를 원합니다.
5. **하루 분량 조절.** 하루 목표량, 몇 개만 반복하기를 원합니다.
6. **방해받지 않기.** 광고 오클릭, 끌 수 없는 잠금화면, 복잡해진 리뉴얼 UI가 큰 감점 요인입니다. "쓸데없는 기능을 더하기보다 꼭 필요한 것만 다듬어 달라"는 리뷰도 있습니다.

### 보강할 것

**1순위: 요구가 크고 지금 빠져 있음**
1. **학습 기록 백업 내보내기·가져오기.** 로그인 없이 파일로 기기 이동과 폰·태블릿 병행을 지원합니다. 가져오기 전 상태를 되돌릴 수 있게 합니다. 나는 영단어와 영단어 마스터가 이미 제공합니다.
2. **오답·취약 단어장과 "틀린 단어만 다시 시험".** 지금은 학습 결과 화면과 하루 요약에서만 다시 연습할 수 있습니다. 정답률이 낮거나 최근 틀린 뜻을 모은 상시 단어장을 만들고, 거기서 바로 시험 보게 합니다.
3. **학습량 설정.** 하루 새 단어 수(지금은 20개 고정)와 한 번에 할 개수(지금은 5개 고정)를 바꿀 수 있게 합니다.
4. **학습 알림과 홈 위젯.** 정한 시각에 "오늘 복습 n개" 알림을 보내고 눌러서 바로 복습하게 합니다. 위젯에는 연속 학습일과 복습 수를 보여 줍니다. 잠금화면 노출을 대신합니다.
5. **테스트 흐름 옵션.** 단어가 나올 때 발음 자동 재생, 정답이면 0.6초 뒤 자동으로 넘기기를 켜고 끌 수 있게 합니다. 오답일 때는 지금처럼 멈춥니다.
6. **단어 목록에서 영어만·뜻만 보기 전환.** 목록 위에 버튼을 두고 눌러서 가린 것을 확인합니다.

**2순위: 문제 유형과 콘텐츠**
7. **문장 빈칸 퀴즈와 듣고 뜻 고르기.** 뜻마다 예문 2개가 있어 빈칸 문제를 바로 만들 수 있습니다. 수능 문맥 추론과도 맞습니다.
8. **듣기 개선.** 백그라운드 재생, 수면 타이머, 영-한 교차·랜덤 순서, 즐겨찾기·오답 단어장만 반복 듣기를 넣습니다. 지금은 화면을 닫으면 멈춥니다.
9. **콘텐츠 보강.** 발음기호, 반의어, 파생어, 혼동어 팁(affect/effect 등)을 추가합니다. 콘텐츠 파이프라인에서 직접 작성해야 해서 시간이 가장 많이 듭니다.
10. **"이미 알아요"로 넘기기.** 익히기 카드에서 아는 단어를 건너뛰되, 뜻 확인 문제는 한 번 풀게 합니다.
11. **복습 간격 확장과 '마스터' 졸업.** 지금은 최대 30일 간격으로 계속 돌아옵니다. 60·120일 간격을 추가하고 졸업 상태를 두어, 2,594개 뜻의 복습량이 계속 불어나지 않게 합니다.

**3순위: 차별화 후보, 범위가 큼**

- **나는 영단어**는 오프라인·가입 없음·빈도순 코스·소단위 학습·백업까지 우리와 방향이 거의 같고, 표제어 수(8,704개), 팁, 게임, 백업이 앞섭니다. 우리 쪽 차별점은 네 가지입니다: 다의어를 뜻 단위로 따로 복습하는 일정, 뜻·철자를 분리한 기록, 사람 검수를 거친 자체 콘텐츠, 광고 없음. 위 1순위 항목 가운데 백업, 알림, 학습량 설정을 갖추지 않으면 기능 표에서 밀립니다.
