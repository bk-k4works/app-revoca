# 중학 학년·레벨 편성 점검과 구현 기준

점검일: 2026-10-16. 상태: 공식 기준과 현재 데이터·코드 점검 완료, 개별 어휘의 학년 배정 및 앱 기능은 미구현.

전체 기본 어휘 3,000개를 제작 대상으로 유지하되, 이를 전부 ‘중학 필수’로 표시하지 않는다. 초등 복습·중1·중2·중3·고교 연계를 구분하고, 학년 추천과 의미별 난이도를 별도로 관리한다. 기존 100개는 검증 표본이며 300개를 출시 완료 기준으로 삼던 계획은 이 문서로 대체한다.

> 최신 진행 순서: 사용자 요청에 따라 제공 PDF의 단어·뜻·예문·보조 데이터를 먼저 확보한다. 학년·난이도는 원고 전수검사를 하면서 별도 편성 원장에 정리한다. 분류 미완료를 원천 데이터 정리의 선행 차단 조건으로 삼지 않는다. [PDF 확보 결과와 Day·Part 활용안](pdf-content-import.md)을 참고한다.

## 1. 공식 기준에서 확인한 것

| 항목 | 확인 내용 | 앱에서의 해석 |
| --- | --- | --- |
| 기본 목록 | 대표 어휘 3,000개 | 초·중·고에 걸친 제작 원천이며 중학교 전용 목록이 아님 |
| `*` | 초등 권장 800개 | ‘중학 핵심 800개’라는 기존 설계 표현을 정정 |
| `**` | 중학교와 고교 공통과목 권장 1,200개 | 중1·중2·중3 구분이나 중학교 전용 필수 목록을 뜻하지 않음 |
| 무표시 | 나머지 과목 권장 1,000개 | 고교 연계 등을 검토하되 표시만으로 개별 의미의 난이도를 확정하지 않음 |
| 중학교 학습량 | 1~3학년군 총 학습 어휘 1,500개 이내 | 초등 학습 어휘와 겹치는 총량이며, 매 학년 1,500개 또는 중학교 신출 1,500개라는 뜻이 아님 |

근거: [KICE Word Lister 안내 자료](https://www.goe.go.kr/resource/old/BBSMSTR_000000030136/BBS_202307111028067791.pdf), 물리적 3쪽의 별표 3 인용 및 37~40쪽의 어휘 수 설명. 저장된 PDF의 3쪽과 38쪽을 이미지로 대조했다. 1~3학년군 기준에는 전국 공통의 중1·중2·중3별 고정 단어 배정표가 제시되어 있지 않다. 학교·교과서 범위와 앱의 추천 학년은 별도로 근거를 수집해야 한다.

교과서 학습량 기준을 앱 콘텐츠의 상한으로 적용하지 않는다. 여러 교과서의 합집합, 복습·심화, 파생어 및 추가 의미를 포함하는 앱은 더 많은 내용을 제공할 수 있다. 다만 고유 표제어 수, 의미 카드 수, 학년 간 중복 수를 구분해 표시한다. 같은 단어를 세 학년에서 복습한다고 단어 수를 세 번 더하지 않는다.

### 교육과정 전환

| 학년도 | 중1 | 중2 | 중3 |
| --- | --- | --- | --- |
| 2026 | 2022 개정 | 2022 개정 | 2015 개정 |
| 2027 이후 | 2022 개정 | 2022 개정 | 2022 개정 |

[교육부 고시 제2022-33호 부칙](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&m=0404&opType=N&s=moe&statusYN=W)은 중1에 2025-03-01, 중2에 2026-03-01, 중3에 2027-03-01부터 적용한다. 교과서 연결에는 교육과정 연도·출판사·저자·학년·단원을 함께 저장한다. 현재 원천은 2022 목록뿐이므로 2026 중3 내신 범위까지 검증됐다고 표시할 수 없다.

## 2. 현재 구현에서 발견한 누락

집계 원본과 파일 해시는 [점검 기록](../analysis/content-grade-level-audit.json)에 남겼다.

| 점검 대상 | 현재 상태 | 필요한 보완 |
| --- | --- | --- |
| 원천 3,000개 | `*` 800 / `**` 1,200 / 무표시 1,000, 학년·난이도 없음 | 공식 원천은 보존하고 별도 편성 데이터를 연결 |
| 앱 파일럿 | 100개 표제어 = `*` 27 / `**` 40 / 무표시 33 | 학년별 대표 표본이나 중학 핵심 목록으로 사용하지 않음 |
| 의미 154개 | 추천 학년·난이도·교과서 근거 없음 | 의미별 분류 및 근거 기록 |
| 단어장 편성 | `make_decks()`가 초등 표시 유무로만 나누고 품사·충돌·빈도 또는 알파벳 순서를 사용 | 학년·레벨·선행 의미를 먼저 반영한 순서로 변경 |
| 정식 빌드 | 대표 의미 1개/표제어만 허용, 기본 기대 수량 300 | 다의어 승인·패키징 지원, 표제어/의미 수 분리, 편성 완성도 검사 |
| 앱 | 학년별 학습 경로·레벨 선택 없음 | 학년 추천, 수준별 시작점, 복습 경로 제공 |

`content/config.json`의 `releaseSize: 300`은 현재 코드가 읽어 출시 수량을 결정하는 값이 아니다. 실제 `build` CLI와 함수에 기본값 300이 별도로 남아 있다. 이 수량 검사를 통과해도 학년별 콘텐츠가 준비됐다는 뜻은 아니다. 이번 점검은 설계를 수정한 것이며 출시 검증 코드에 학년 조건을 추가한 것은 아니다.

## 3. 학습 경로와 난이도

아래는 **앱 편집 기준 제안**이다. 교육부의 학년별 필수 단어표로 표시하지 않는다. 실제 단어 배정은 교과서 근거와 의미 검토 후 확정한다.

| 경로 | 편집 목적 | 우선 검토할 내용 |
| --- | --- | --- |
| 중학 준비 | 초등 어휘의 빈틈 보완 | 일상·학교·수량·시간, 기본 동작과 대표 의미 |
| 중1 추천 | 익숙한 상황에서 기본 표현 사용 | 일상 의사소통, 기본 연어, 학교생활에 필요한 의미 |
| 중2 추천 | 주제·의미·표현의 범위 확장 | 경험·비교·원인 설명, 주요 다의어와 품사 확장 |
| 중3 추천 | 긴 문맥과 추상적 의미 이해 | 의견·근거·사회·과학 주제, 문맥에 따라 달라지는 의미 |
| 고교 연결 | 중학교 이후 학습 준비 | 고교 공통과목 및 그 밖의 기본 어휘와 확장 의미 |

중1에도 어려운 단어가 있고 중3에도 복습할 쉬운 단어가 있으므로 학년을 난이도로 환산하지 않는다. 각 의미에는 별도로 다음 수준을 판정한다.

- **기초:** 익숙하고 구체적인 대표 의미, 짧고 직접적인 문맥으로 이해 가능.
- **기본:** 주제 어휘·주요 확장 의미·연어를 알아야 문맥을 이해 가능.
- **도전:** 추상성·다의성·의미 구별·문맥 의존성이 높아 추가 설명이나 선행 학습이 필요.

단어 길이, 알파벳 순서, 별표 개수만으로 수준을 정하지 않는다. 예문 자체의 어휘·문법 부담도 따로 점검한다. CEFR이나 학교 성취수준을 이 세 단계에 자동 대응시키지 않는다.

동일한 표제어라도 의미에 따라 최초 추천 경로가 달라질 수 있다. 의미를 여러 학년에서 복습할 때는 같은 sense ID를 공유한다. 학년이나 레벨을 고쳐도 ID를 바꾸지 않으며, 다른 의미를 기존 학습 기록에 합치지 않는다.

## 4. 추가할 편성 데이터

아래는 후속 구현 계약이다. 아직 현재 스키마·SQLite·앱에 추가된 필드가 아니다. 원천 CSV의 공식 표시는 편집 판단과 분리해 유지한다.

| 필드 | 단위 | 용도 |
| --- | --- | --- |
| `curriculumVersion` | 편성 묶음 | `2015` / `2022`, 교과서 근거를 혼합하지 않음 |
| `senseId` | 의미 | 기존 학습 기록과 연결되는 고정 ID |
| `firstStudyTrack` | 의미×교육과정 | `bridge` / `middle1` / `middle2` / `middle3` / `highBridge`, 미분류는 `null` |
| `reviewTracks` | 의미×교육과정 | 같은 의미를 복습할 경로, 신규 단어 수에는 중복 산입하지 않음 |
| `difficulty` | 의미 | `foundation` / `standard` / `challenge`, 근거 없으면 `null` |
| `prerequisiteSenseIds` | 의미 | 먼저 학습할 의미, 순환 관계 금지 |
| `evidenceRefs` | 분류 판단 | 출처 URL·판본·쪽/단원·학년·해당 의미·확인일 및 판단 근거 |
| `classificationReview` | 분류 판단 | 제안/근거 부족/검토 완료, 실제 검토 주체·방법·일자·입력 해시 |

교과서에 등장했다는 사실과 그 학년에서 처음 배워야 한다는 판단을 구분한다. 가능한 여러 출판사의 같은 학년 자료를 비교하고, 한 자료만으로 전체 학생의 필수 어휘라고 일반화하지 않는다. 텍스트가 같아도 품사·뜻이 다르면 다른 의미 근거로 기록한다. 일반 교과서 근거 수집은 해당 단어·의미의 등장 근거를 기록한다. 사용자가 별도로 제공하고 활용을 요청한 PDF 두 개의 뜻풀이·예문은 출처를 연결한 로컬 원천으로 보존하며, 배포 이용 상태와 자체 작성 원고를 구분한다.

학년 근거가 없는 항목은 미분류 대기열로 둔다. Codex의 편집 제안과 교사의 확인을 서로 다른 검토 방식으로 기록하며, 자동 분류를 사람 승인으로 바꾸지 않는다. 이번에는 교과서별 어휘 전체 대조나 3,000개 개별 학년 배정을 수행하지 않았다.

## 5. 제작·검증 순서

1. **단어 데이터 확보:** 제공 PDF 본문 2,300개와 보조 자료를 먼저 정리한다. 공식 3,000개 목록도 유지하며 출처·중복 관계를 남긴다. Day·Part를 학년으로 치환하지 않는다.
2. **전수검사와 별도 편성:** 뜻·품사·예문을 전수 대조하고 의미를 나누면서 학년·난이도·교과서 근거를 별도 원장에 기록한다. 근거가 없으면 미분류로 두고, 학년마다 임의로 1,000개씩 배정하지 않는다. 필요한 새 원고는 API 키 없이 Codex 로컬 경로로 작성·검수한다.
3. **파이프라인 보완:** 검수된 의미와 원천 항목의 연결, 편성 스키마, 의미별 다중 승인, 학년·Day 단어장, 표제어/의미 수 집계를 구현한다. 기존 `build`의 단일 대표 의미 제약을 해결한다.
4. **앱 반영:** 학년·레벨별 목록, 시작 수준 선택, 새 학습/복습 수 표시를 추가한다. 학년 이동과 콘텐츠 업데이트 후에도 의미별 진도·시험 범위를 유지한다.
5. **출시 점검:** 목표 경로별 누락·미분류·근거 부족, 예문 난이도, 오답 유일성, 승인 상태를 검증한다. 근거 자료에서 어떤 표제어·의미를 얼마나 다루는지 분모와 함께 보고하고, 교과서 전체를 대조하지 않았다면 완전 커버라고 표시하지 않는다.

새 어휘를 추가할 때는 해당 의미의 학년·난이도와 관련 단어장의 순서·선택지를 변경 검수한다. 분류만 바뀌면 텍스트가 같은 음성을 다시 합성할 필요는 없다. 현재 `audit`는 편성 변경을 다루지 않으므로 후속 구현에서 편성 해시와 영향받는 단어장 검수도 포함해야 한다.

## 6. 이번 점검 범위

- 확인 완료: 공식 권장군·중학교 총량·시행 일정, 현재 3,000개 원천과 100개 파일럿 분포, 스키마·빌드·단어장 편성의 누락.
- 반영 완료: 본 설계, 파이프라인 진행 순서 및 README의 출시 범위 설명 정정.
- 후속 작업: 교과서별 근거 확보, 개별 의미의 학년·난이도 배정, 정식 다의어 빌드, 학년별 앱 경로. 현재 앱 데이터·기존 승인 기록은 이번 점검으로 바뀌지 않았다.
