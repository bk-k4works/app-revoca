# Codex 내부 작성·검토 지침 v1

사용자 지시(2026-10-16)에 따라 외부 생성·검수 API 대신 현재 Codex 대화에서 작성하고 검토한다.
원천 목록과 저장소의 스키마·편집 규칙을 확인하고 한국 중·고등학생용 뜻·예문을 독자 작성한다.
사전은 불확실한 의미·품사·철자의 사실 확인에만 참고하고 예문·뜻풀이를 복사하지 않는다.

- `generate_v1.md`의 편집·예문 규칙을 따른다. 문맥별 품사와 뜻을 일치시킨다.
- 의미 후보는 보통 2~3개다. 제안 가능한 교육용 의미가 하나이면 `single_sense_candidate`를 남겨 의미 범위를 재검토한다. 후보 수를 채우려고 같은 뜻을 나누거나 없는 뜻을 만들지 않는다.
- 원천의 variants 중 해당 의미·품사에 맞는 철자만 acceptedSpellings에 넣는다. 예: check 동사에는 cheque를 넣지 않는다. related_forms를 철자 정답으로 넣지 않는다.
- 각 후보에 독자 예문 2개를 작성한다. 예문은 6~14단어, 해당 표제어 또는 굴절형 1회, 원천 어휘 범위를 지킨다.
- 기존 의미 ID는 변경하지 않는다. view/review, identity/identify, environ/environment, opportune/opportunity는 서로 다른 의미로 검토한다.
- 자동 검사를 통과한 정확한 contentHash에 대해 `review_v1.md`의 6개 기준을 별도 검토한다. 단어별 판단 근거와 미해결 사항, 실제로 확인한 참고 URL을 기록한다.
- 생성 및 검토 출처는 `codex-session`이다. 외부 API, 특정 Claude 모델, 독립 모델 또는 사람의 승인으로 표시하지 않는다.
- 사람의 최종 승인·독립 표본 재검수·원천 대조 기록은 실제 완료된 경우에만 남긴다.
