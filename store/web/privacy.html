개인정보처리방침

게시 전 검토 초안입니다. 아래 고객지원 이메일의 보관 기간·처리 위탁 현황을 운영자가 확인하고 시행일을 확정한 뒤 게시해 주세요.

K4WORKS는 리보카 앱의 개인정보 처리 방식을 아래와 같이 안내합니다. 이 초안은 리보카 1.0.0의 구현을 기준으로 작성했습니다.

앱에서 처리하는 정보

리보카는 회원가입 없이 사용할 수 있습니다. 이름, 전화번호, 이메일 주소를 앱에서 입력받지 않으며, 광고·행동 분석·사용자 추적 SDK를 사용하지 않습니다.

학습 진행 상태, 퀴즈 결과, 복습 일정, 즐겨찾기, 시험 범위, 학습 목표와 알림·화면 설정은 서비스를 제공하기 위해 사용자의 기기에 저장됩니다. 이 정보를 K4WORKS 서버로 전송하거나 K4WORKS가 열람하는 기능은 없습니다.

기기 기능과 음성 재생

학습 알림은 사용자가 알림을 켰을 때 권한을 요청하며, 기기 안에서 예약됩니다. 알림 시각을 맞추기 위해 기기의 시간대 설정을 사용합니다. Android 홈 화면 위젯에는 기기에 저장된 학습 요약이 표시됩니다.

단어와 예문 읽기는 기기의 텍스트 음성 변환(TTS) 기능을 사용합니다. 재생할 학습용 텍스트가 기기 TTS 엔진에 전달되며, 엔진과 음성 설정에 따라 해당 제공자의 네트워크 서비스를 사용할 수 있습니다. TTS 제공자의 처리 방식은 해당 서비스의 개인정보처리방침을 따릅니다.

보관과 삭제

학습 정보는 앱 데이터가 기기에 존재하는 동안 보관됩니다. Android에서는 시스템 설정에서 앱 저장공간의 데이터를 삭제하거나 앱을 제거할 수 있습니다. iOS에서는 앱을 삭제하여 앱의 로컬 데이터를 제거할 수 있습니다. ‘앱 정리하기’는 데이터를 보존할 수 있습니다.

운영체제의 백업·기기 이전 설정에 따라 앱 데이터가 사용자 계정의 백업에 포함되거나 복원될 수 있습니다. 해당 백업은 사용자가 운영체제의 백업 설정에서 관리합니다. 리보카 자체 계정 동기화 서비스는 제공하지 않습니다.

고객지원 문의

사용자가 help@k4works.com으로 직접 문의하면 회신을 위해 이메일 주소와 문의 내용을 처리하게 됩니다. 문의에 학습 기록이나 개인정보가 포함된 화면을 첨부할 때에는 불필요한 정보를 가려 주세요.

게시 전 확정 항목: 문의 처리의 법적 근거, 문의 해결 후 보관 기간 및 삭제 절차, 이메일 서비스 사업자에 대한 처리 위탁·국외 이전 해당 여부와 필요한 고지.

문의와 권리 행사

개인정보 관련 문의 또는 이메일 문의 기록의 열람·정정·삭제 요청은 K4WORKS 고객지원 help@k4works.com으로 보내 주세요. 기기에만 저장된 학습 정보는 K4WORKS가 원격으로 조회하거나 삭제할 수 없습니다.

변경 안내

데이터 처리 방식이 변경되면 이 페이지의 내용을 갱신하고 필요한 경우 앱에서 안내합니다. 시행일은 최초 게시 시 확정합니다.
