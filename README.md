# 리보카 (re:voca)

**고등학생의 내신·수능 영어 단어** 학습을 1차 목표로 하는 Flutter MVP입니다. 중학 영단어는 앱에서 '준비 중'으로 표시합니다.

현재 앱에는 고등 트랙 개발용 콘텐츠가 들어 있습니다. 고등 트랙 **2,000개 전체**(뜻 2,594개, 예문 5,188개)를 101개 단어장(고교 기본 540, 아는 단어·새로운 뜻 59, 고교 핵심 881, 핵심 숙어 89, 수능 심화 431)으로 묶었습니다. 2,000단어 목록은 제공 교재의 **표제어만** 참고했습니다. 단계는 교육과정 목록 표시로, 순서는 공개 빈도 자료로 정했습니다. 뜻과 예문은 모두 직접 작성했습니다. 방침과 진행 상황은 [고등 영단어 트랙](docs/highschool-content.md)에 정리했습니다. 이전 중학 파일럿(100개 표제어)은 `content/previews/pilot-v2/`에 보존했습니다.

## 구현한 기능

- 오늘 할 복습과 새 단어 추천, 진행 중 학습 이어하기
- 단어장 목록·검색·단어 상세, 나의 시험 범위에 단어 담기
- 뜻 선택과 철자 입력 채점, 의미별 허용 철자 처리, 모르겠어요, 오답 재연습
- 다의어별 품사·연어 표시, 오답 후보가 부족한 의미는 뜻 공개 후 직접 평가
- 단어 상세에서 두 번째 예문·번역·발음 확인
- 뜻과 철자를 분리한 복습 일정·학습 기록·주간 활동
- SQLite를 통한 답안·학습 위치·시험 범위 영구 저장
- 기기 TTS의 단어·예문 발음과 전경 반복 듣기, 속도·반복 횟수·뜻/예문 포함 설정
- 밝은/어두운 테마, 스크롤과 시스템 글자 크기 대응

익히기·듣기·즉시 재시도는 장기 성취를 올리지 않습니다. 이미 예정된 날짜보다 일찍 푼 문제도 추가 연습으로 기록합니다. 복습 규칙은 초기 제품 규칙이며 효과가 검증된 개인화 모델로 주장하지 않습니다. 단어별 의미·철자 상태는 따로 저장하지만, 현재 세션은 선택된 단어의 두 방식 모두를 출제하고 아직 복습일이 아닌 방식은 연습으로 처리합니다.

듣기는 화면을 닫거나 앱이 백그라운드로 가면 멈춥니다. 듣기 화면 안의 일시정지는 현재 단어부터 다시 재생하며, 화면을 닫은 뒤 듣기 위치를 복구하는 기능은 없습니다. TTS는 기기에 설치된 영어·한국어 음성에 의존합니다. 텍스트는 오프라인에서 사용 가능하지만 모든 기기의 오프라인 발음을 보장하지 않습니다.

## 실행

검증 환경은 Flutter 3.41.6 / Dart 3.11.4, Android SDK 36, Xcode 27.0입니다. iOS 최소 버전은 현재 15.0으로 설정했습니다.

```sh
flutter pub get
flutter devices
flutter run -d <device-id>
```

```sh
flutter analyze
flutter test
flutter test integration_test/persistence_test.dart -d <ios-simulator-id>
flutter build apk --debug
```

이 환경에서 Flutter SDK는 `/Users/bkkwon/Sdk/flutter`에 있습니다. Android 개발용 설치 파일은 `build/app/outputs/flutter-apk/app-debug.apk`에 생성됩니다. iOS는 지정한 iPhone 시뮬레이터에서 `flutter run -d <device-id>`로 실행을 확인했습니다. 현재 Xcode/Flutter 조합의 일반 `flutter build ios --simulator` 명령에서는 다중 아키텍처 처리 오류가 발생했으므로 특정 시뮬레이터를 지정한 실행을 사용합니다.

## 코드 구조

```text
content/                 원천 3,000개·프롬프트·스키마·중간 산출물·검수 기록
tool/content/            S0–S7 Python CLI와 자동 테스트
assets/content/          콘텐츠 SQLite·카탈로그·첫 단어장 음성·개발 fixture
lib/domain/              어휘·학습 세션·복습 규칙
lib/data/                SQLite 저장소
lib/application/         학습 동작과 상태 관리
lib/services/            검수 음성 재생·다운로드 팩·기기 TTS
lib/ui/                  테마와 화면
test/                    학습 규칙·저장 실패·화면 흐름 테스트
integration_test/        네이티브 SQLite 저장/재연결 검증
analysis/                분석·기획·디자인·검증 기록
```

앱은 읽기 전용 콘텐츠 SQLite에서 검색·퀴즈 색인을 읽고 학습·상세·듣기 단위로 예문과 설명을 불러옵니다. 사용자 진행은 별도 SQLite DB에 저장합니다. 기존 JSON은 개발 fixture 및 문체 참고 원본으로 남겨 둡니다. `LearningStore`와 `SpeechService` 인터페이스를 통해 저장 방식과 음성 공급자를 교체할 수 있습니다. 학습에는 서버나 계정이 필요하지 않습니다.

## 검증과 다음 단계

2026-10-16 기준 Python 파이프라인 테스트 51개(PDF 추출 12개 포함)를 통과했습니다. 기존 Flutter 단위·위젯 테스트 31개, iOS 네이티브 SQLite 통합 테스트 3개의 통과 기록도 있습니다. 파일럿 154개 의미·308개 예문 로딩, 의미별 허용 철자, 5개 학습 완료 및 뜻·철자 복습 일정 저장도 검증했습니다. 작은 화면(320×720)·글자 200%의 홈/단어장/기록 탭, 한 라운드와 오답 연습, 시험 범위 저장, 듣기 종료를 검증했습니다. 모든 기기와 모든 화면의 접근성을 검증한 것은 아닙니다. iPhone 시뮬레이터의 실제 홈 화면은 [여기](analysis/screenshots/ios-home.png)에서 확인할 수 있습니다.

출시 전에는 다음 작업이 필요합니다.

1. 고등 트랙 사람 승인(검수표 `content/highschool/v1/review/human/review.csv`) 후 `hs-release`로 출시 패키지 만들기. 작성자 재검토와 Codex 독립 검토는 끝남. 중학 트랙은 그 후에 시작
2. 검수된 발음 음성 확보 또는 기기별 TTS 품질 확인, 필요한 음성 다운로드 전략 결정
3. 실제 학생 대상 학습 흐름 확인과 Android/iPhone 실기기·키보드·음성 검증
4. 교과서별 콘텐츠 연결, 직접 입력/가져오기 등 시험 범위 기능 확장
5. 스토어 식별자·아이콘·릴리스 서명·개인정보 안내·배포 설정

현재 Android 서명은 Flutter 기본 개발 설정이며, 스토어 배포 또는 서버 배포는 수행하지 않았습니다. 로그인·동기화·공유 단어장·교사 관리·결제·잠금화면 재생도 아직 구현하지 않았습니다.

## 콘텐츠 파이프라인 구현 (2026-10-16)

제공 PDF 두 개를 로컬 원천 라이브러리로 정리했습니다. 고교 2,000개·중학교 300개(고유 철자·구 2,240개), 예문·번역 3,642쌍, 표현 300개, 관련어 153개와 어원 보조 카드 6개를 확보했습니다. Day·Part·Half 및 문제·색인 등 697쪽 전체를 보존했습니다. 중학교 첨부본은 표지의 1,200개 전체가 아닌 Day 1–15 발췌본입니다. 학년 분류는 전수검사 과정으로 미루며, 앱 배포 이용 권한과 편집 승인은 확인 전입니다. 재현 명령과 코스 활용안은 [PDF 기록](docs/pdf-content-import.md)에 있습니다.

API 키 없이 Codex 내부에서 표본 100개를 작성·검토하는 경로를 추가했습니다. 의미 후보 154개와 예문 308개를 작성했고 100개 모두 자동 검사를 통과했습니다. [파일럿 검토 화면](content/pilots/pilot-v1/review.html)에서 원고·검토 메모를 읽고 [검수 CSV](content/pilots/pilot-v1/codex.review.csv)에 사람의 결정을 기록할 수 있습니다. 실제 사람 승인과 앱 배포 반영은 아직 하지 않았습니다.

교육청 게시 원천에서 기본 목록 3,000개를 추출하고 초등 표시 800개·공통과목 표시 1,200개를 검사했습니다. 원문에 대한 두 사람의 대조는 아직 필요합니다. 문체 참고 50개도 전문 검수 전 초안이며, 배포 가능한 승인 골드셋은 아닙니다.

배치 생성·독립 LLM 검수·자동 검사·사람 검수 CSV·10% 재검수·음성 합성/ASR/청취 검수·버전별 SQLite/음성 ZIP 빌드까지 구현했습니다. 앱은 의미 ID로 학습하며 기존 30개 기록을 트랜잭션으로 이전하고, 같은 품사·유의어 배제·비슷한 뜻 길이의 선택지를 사용합니다. 로컬/번들/다운로드 음성이 없으면 기기 TTS로 읽습니다.

현재 앱에는 100개 표제어·154개 의미의 개발 전용 SQLite가 포함되어 있습니다. API 과금 호출, 출시 승인 원고 제작, 실제 음성 합성·청취, 팩 업로드는 수행하지 않았습니다. 승인되지 않은 패키지의 release 실행과 검수 기록이 부족한 콘텐츠 빌드를 차단합니다. 학년·난이도 편성과 그에 대한 출시 검사는 후속 작업입니다. 상세 명령과 남은 사람 검수 단계는 [실행 안내](docs/content-pipeline-operations.md)에 있습니다.
